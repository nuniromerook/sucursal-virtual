# Skill de Asesoría de Flujo y Optimización de Decisiones (better-way-advisor)

Permite al agente detenerse proactivamente al escanear el proyecto para evaluar si la solución que se está por aplicar es la mejor disponible o si existe una alternativa con mejor experiencia de usuario y arquitectura.

## Procedimiento de Ejecución

1. **Escaneo de Viabilidad**:
   - Contrastar la idea solicitada contra la base de datos, los componentes existentes y el flujo real de trabajo de la carnicería.
   - Detectar si la idea original genera deuda técnica, fricción en celulares gama baja o duplicación de datos.

2. **Formulación de la Alternativa**:
   - Reducir pasos innecesarios para el cliente o cajero.
   - Simplificar código y estado de React.

3. **Consulta al Usuario**:
   - Notificar al usuario con el titular:
     "💡 **Hay una mejor forma de hacerlo en base a tu flujo**"
   - Ofrecer las opciones [Aceptar] o [Ignorar].
   - Esperar la decisión del usuario antes de aplicar cambios.
